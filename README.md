# 三色图制作器

简体中文 | [English](README.en.md)

在线制作「稳定 / 速度 / 便宜」这类三色韦恩图表情包，还能一键生成转圈圈的动图和视频。

**在线使用：<https://justlikecheese.github.io/sansetu/>**

## 功能

- **默认效果与原图一致**：圆的位置、配色、文字位置和字号都按原图测量还原。
- **颜色、文字全部可改**：七个区域各自的底色、文字、字色、字号，以及加粗、斜体、下划线、删除线；文字支持换行。
- **在图上直接编辑**：单击文字就能改字；右键打开菜单改颜色、字号、样式、圆的大小。
- **拖动编辑（默认关闭，防误触）**：打开「拖动编辑」开关后，可以拖动文字、拖文字框的角改字号、拖圆的边改大小（按住 Shift 三个圆一起变）、拖画布边缘改边距。
- **撤销 / 重做**：Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做（Mac 上用 ⌘）；预览区也有按钮。
- **圆圈 DIY**：半径、圆心距离、三个圆各自的大小、描边粗细和颜色。
- **预设**：多套文案和配色；交集颜色可以自定义，也可以由三个圆自动平均混色或正片叠底混色。
- **静态图导出**：PNG、JPG、WebP、SVG、BMP、ICO（浏览器支持时还有 AVIF），0.5x～4x 尺寸，可复制到剪贴板。
- **动图 / 视频导出**：GIF、APNG、WebP 动图、MP4 / WebM 视频；可以下载、复制，或通过系统分享面板直接发送。
- **转圈圈动画**：转几圈、方向、时长、停顿、转速曲线、中心字特效、文字保持正向、尺寸、循环都能调；帧率可以填 1～120 之间任意值（GIF 最高 50，APNG / WebP 最高 60，视频最高 120）。
- **可暂停的预览**：单击或双击预览画面、生成好的动图或视频都可以暂停 / 继续。
- **多语言**：简体中文、繁體中文、English、日本語，按浏览器语言自动选择。
- **分享链接**：一键复制带有全部设置的链接；修改会自动保存在本地浏览器里。

纯前端实现，没有构建步骤、没有第三方脚本。下拉框、勾选框、开关、滑杆、数字框、取色器都是自己实现的组件（`ui.js`），不依赖浏览器自带控件的外观和弹窗；GIF / APNG / WebP 动图的封装也是自己写的。图片全部在浏览器本地生成，不会上传。

> 剪贴板限制：浏览器不能把 GIF / 视频文件以「文件」的形式放进剪贴板，复制后粘贴到文档、邮件等地方可以保留动画，但微信、QQ 等聊天软件通常只收静态图，发送动图请用「下载」或「分享」。

## 本地运行

直接用浏览器打开 `index.html` 即可，或者起一个静态服务器：

```bash
python -m http.server 8000
```

## 文件

- `index.html` / `style.css`：页面与样式
- `app.js`：绘制、交互、撤销、导出
- `ui.js`：自定义表单组件（勾选框 / 开关、滑杆、数字框、下拉选择、取色器）
- `i18n.js`：界面文案和各语言的文案预设
- `gif.js`：GIF89a 编码器（流行色调色板 + LZW）
- `encoders.js`：APNG、动态 WebP、BMP、ICO 封装
